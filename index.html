NFT Collections (detected)

Source: every deployed realm (genesis included) that imports a GRC721/GRC1155-style library AND defines a matching function (Mint/OwnerOf/TokenURI/...). No central registry exists for NFTs, so this is best-effort detection, not a guarantee — a realm that merely references someone else's collection (a marketplace, a staking contract) can still slip through if it redeclares a matching function name. Genesis-deployed realms are scanned too, cached in your browser after the first visit.

Scan Wallet

Checks the address below (read-only — no keys, no signing) for: native GNOT balance, plus every fungible token and detected NFT collection from the other two tabs. Token/NFT coverage is limited to whatever those tabs found, so their caveats apply here too. Amounts are shown human-scale wherever a token's decimals could be determined on-chain; GRC20 doesn't reliably expose this, so a token that doesn't will show its raw on-chain units instead, labeled as such.

Native balance

GNOT is the chain's native token (like ETH or ATOM) — held directly on the account, not through a GRC20 realm, so it's checked separately from everything below.

Whale Watch

Native GNOT balance for every address this site has seen deploy a package, call a realm, execute a Gnoswap swap, or hold a genesis balance allocation — ranked richest first. The indexer has no accounts/balances query at all, and the chain's own auth module exposes no "list all accounts" query either (checked directly against the tm2/gno.land source), so each balance is a real, exact RPC read, not an estimate — but this can only rank addresses this site has actually observed, not literally every address that has ever existed on the chain.
