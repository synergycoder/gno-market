🪙 Fungible Tokens (GRC20)

Source: on-chain registry gno.land/r/demo/defi/grc20reg — genesis-deployed tokens are already included, since registration happens in each token's init() regardless of how it was deployed. Decimals and logos come from the same community-curated registry GnoScan's own token page reads (onbloc/gno-token-resource on GitHub). Holder counts are derived by replaying every Transfer event chain-wide (not just calls to the token's own realm — a swap through Gnoswap's router, for example, emits Transfer events for the traded tokens too) and counting addresses with a positive balance — close to GnoScan's own numbers but not always exact: a balance assigned directly in a realm's init() rather than minted via a Transfer event wouldn't be reflected here.

🖼️ NFT Collections (detected)

Source: every deployed realm (genesis included) that imports a GRC721/GRC1155-style library AND defines a matching function (Mint/OwnerOf/TokenURI/...). No central registry exists for NFTs, so this is best-effort detection, not a guarantee — a realm that merely references someone else's collection (a marketplace, a staking contract) can still slip through if it redeclares a matching function name. Genesis-deployed realms are scanned too, cached in your browser after the first visit.

💬 Social Realm Activity

Best-effort detection, not a guarantee: a realm is flagged here if its source mentions "board"/"blog"/"social" and defines a thread/post/reply-style function (e.g. CreateThread, CreatePost, CreateBoard) — or, independently, if it defines something that creates a discussion space (a channel/board/thread/room/group) together with something that posts content into one (a message/post/comment/reply), regardless of exact naming or whether those specific words appear anywhere (added after a real chat realm using CreateChannel/PostMessage was found slipping through both checks above). 🐋 Whale Watch

Native GNOT balance for every address this site has seen deploy a package, call a realm, execute a Gnoswap swap, send or receive a plain native-GNOT transfer, or hold a genesis balance allocation — ranked richest first. The indexer has no accounts/balances query at all, and the chain's own auth module exposes no "list all accounts" query either (checked directly against the tm2/gno.land source), so each balance is a real, exact RPC read, not an estimate — but this can only rank addresses this site has actually observed being active in some way, not literally every address that has ever existed on the chain. Addresses marked Genesis were funded directly in the chain's genesis file rather than observed via a transaction. The size tier is recalculated live from the current list every time it loads, so it adjusts automatically as more wallets are discovered.

🕸️ Dependencies

Which shared packages (p/...) and realms (r/...) get imported by the most other realms — read directly from each realm's own import (...) block, not runtime call traces (Gno transactions only record the top-level caller, never intermediate realm-to-realm hops, so there's no "who actually got called" data to mine).
